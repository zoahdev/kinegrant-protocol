# 如何参与 KineGrant（中文版）

> 全部参与方式的单一入口。仓库：https://github.com/zoahdev/kinegrant-protocol
> 英文原文：`docs/community/PARTICIPATION.md`。

## 1. 贡献代码 / 文档（最简单）

- 阅读 CONTRIBUTING.md 并认领 good-first-issue。
- 示例任务：#12 独立复现 MPT v0.5（22 项用例）；翻译；适配器。

## 2. 做独立实现

- 定义与流程：KGP-RFC-0004 + implementations/RECOGNITION.md。
- 提交 `implementations/<name>/`，附可复现的互操作证据。

## 3. 参与治理 / 投票

- 当前投票：RFC-0003（issue #127，窗口至 2026-08-29）——见 docs/community/RFC-VOTING.md。
- 委员会席位：Discussion #246 + docs/community/STEERING-COMMITTEE.md（提名表：NOMINATION-TEMPLATE.md）。

## 4. 成为试点伙伴

- 免费、无绑定、无生产数据；1–2 个名额。
- 框架：docs/PILOT-PARTNERSHIP.md（中文：.zh-CN.md）。

## 5. 推广 / 引用

- 给仓库点星；提交到开源目录。
- 在论文与演讲中引用规范与 RFC（不作采用/认证声明）。

## 对所有人的边界

- 无代币、无募资、无法律实体、无金融机制。
- 贡献在 Apache-2.0 下公开署名；凭证不可转让、无经济价值。
- 不声称客户、采用、认证、生产就绪或标准认可。
