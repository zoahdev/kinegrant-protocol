# How to Participate in KineGrant

> One entry point for all participation paths. Repo:
> https://github.com/zoahdev/kinegrant-protocol

## 1. Contribute code / docs (easiest)

- Read CONTRIBUTING.md and pick a good-first-issue.
- Example task: #12 independently reproduce MPT v0.5 (22 cases); translations; adapters.

## 2. Build an independent implementation

- Definition and workflow: KGP-RFC-0004 + implementations/RECOGNITION.md.
- Submit `implementations/<name>/` with a reproducible interop-evidence file.

## 3. Participate in governance / voting

- Current vote: RFC-0003 (issue #127, window closes 2026-08-29) — see
  docs/community/RFC-VOTING.md.
- Steering committee seats: Discussion #246 + docs/community/STEERING-COMMITTEE.md.

## 4. Become a pilot partner

- No fee, no lock-in, no production data; 1–2 slots.
- Framework: docs/PILOT-PARTNERSHIP.md (Chinese: .zh-CN.md).

## 5. Promote / cite

- Star the repo; submit to open-source directories.
- Cite the spec and RFCs in papers and talks (no adoption/certification claims).

## Boundaries for everyone

- No tokens, no fundraising, no legal entity, no financial mechanism.
- Contributions are credited publicly under Apache-2.0; credentials are
  non-transferable and have no economic value.
- No claims of customers, adoption, certification, production readiness, or
  standards recognition.
