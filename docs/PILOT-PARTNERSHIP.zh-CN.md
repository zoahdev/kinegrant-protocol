# 试点合作框架（免费技术验证 · 中文版）

> 配套文档：Discussion #205。状态：开放报名中。
> 英文原文：`docs/PILOT-PARTNERSHIP.md`。

## 我们在找什么

1–2 个试点伙伴，拥有测试机器人或智能设备（门、机械臂、摄像头、门禁），端到端验证动作级授权：策略决策 → 短期能力凭证 → 本地闸门 → 签名回执。

## 原则

- **免费、无绑定、无生产数据。** 试点仅使用测试设备与合成数据。
- **我们提供**参考实现、浏览器验证器与集成协助。
- **你获得**可审计的“谁允许了这次动作、仅一次、带签名回执”能力层，并经你同意后获得试点伙伴公开署名。

## 试点范围

1. 在测试设备上定义一个物理动作（例如开门、限位内移动机械臂、用摄像头道具录制）。
2. 在执行器调用前集成动作闸门（Python 参考实现或适配器）。
3. 在相同策略上运行 Machine Permission Test，然后运行试点场景并捕获签名回执。
4. 经你同意后发布可审计 trace：策略 → 能力 → 闸门 → 回执，不含生产数据。

## 边界

- 无安全认证、无生产就绪声明、无标准认可、无法律实体关系、无财务安排。
- 试点是测试环境中的软件验证，不移动生产机械。
- 原生安全系统始终保留否决任何动作的权力。

## 如何报名

回复 Discussion #205 或开 issue，说明：

- 设备与要验证的一个动作；
- 环境（模拟器、实验室、测试台）；
- 约束条件（离线、语言/运行时、时间线）。

## 评审流程

1. 维护者在 7 天内分诊报名。
2. 简短通话或异步沟通确认范围与环境。
3. 分享集成清单；运行试点；结果公开记录。
