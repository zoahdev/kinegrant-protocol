KineGrant रोबोट और अन्य फिजिकल-AI प्रणालियों के लिए एक संकीर्ण अधिकृतिकरण और जवाबदेही परत है। एक्चुएटर द्वारा कोई क्रिया करने से ठीक पहले, KineGrant एक अल्पकालिक, एक-बार उपयोग क्षमता (capability) सत्यापित करता है जो सटीक एजेंट, लक्ष्य, क्रिया, उद्देश्य और नीति निर्णय से बँधी होती है। निष्पादन के बाद, निष्पादक एक हस्ताक्षरित, गोपनीयता-न्यूनतम रसीद उत्पन्न कर सकता है।

KineGrant कोई टोकन, ब्लॉकचैन, रोबोट मिडिलवेयर, मोशन प्लानर या कार्यात्मक-सुरक्षा प्रणाली नहीं है। यह W3C ODRL, W3C Web of Things, IEEE 7012, ROS 2/SROS2, OPC UA, Matter, और मूल सुरक्षा तर्क को प्रतिस्थापित नहीं करता, बल्कि पूरक करता है।

```text
बाहरी नीति/डिवाइस विवरण
            │
            ▼
   KineGrant सीमा अनुकूलक
            │
            ▼
ActionRequest → PolicyEngine → Capability → ActionGate → Actuator
                                                    │
                                                    ▼
                                           हस्ताक्षरित रसीद लॉग
```

## सुरक्षा गुण (v2.65.4)

- डिफ़ॉल्ट अस्वीकार और deny-overrides नीति मूल्यांकन;
- नीति जारीकर्ताओं के लिए स्पष्ट विश्वास सीमा: अविश्वसनीय स्रोत अस्वीकार कर सकते हैं लेकिन कभी अनुमति नहीं दे सकते;
- विश्वसनीय-घड़ी अनुरोध ताज़गी और नीति-विंडो मूल्यांकन;
- Ed25519-हस्ताक्षरित capabilities जिनका जीवनकाल 1–300 सेकंड होता है;
- एजेंट, लक्ष्य, क्रिया, उद्देश्य, अनुरोध digest और नीति digest से बंधन;
- इन-मेमोरी और क्रैश-स्थायी SQLite पुनरावृत्ति स्टोर के साथ परमाणु एक-बार खपत;
- स्पष्ट विश्वसनीय-जारीकर्ता अनुमति-सूची;
- हस्ताक्षरित, हैश-श्रृंखलित क्रिया रसीदें;
- सख्त अनुकूलक जो अज्ञात अधिकृतिकरण प्रतिबंधों को अस्वीकार करते हैं;
- हर कोर वस्तु के लिए सख्त JSON Schema;
- नीति उत्पत्ति, अस्वीकृति, छेड़छाड़, समाप्ति, समवर्ती/स्थायी पुनरावृत्ति, रसीद विश्वास, Schema और अनुकूलकों के लिए परीक्षण।
